**Consolidated Cash Visibility**: Real-time multi-bank, multi-currency position calculation with strict segregation of restricted and operating cash.\n- **Bank Statement Ingestion**: Automated ingestion and checksum deduplication for MT940, CAMT.053, and Excel bank statements.\n- **Intelligent Heuristic Reconciliation**: Rule-based matching engine (exact date, fuzzy date window, reference substring, exact decimal amount).\n- **Maker-Checker Dual Control**: Separation of duties with configurable authorization thresholds for payments, adjustments, and reconciliation sign-offs.\n- **Real-Time SSE Live Stream**: Authenticated Server-Sent Events (`/api/treasury/live-stream`) delivering sub-second balance updates and approval requests.\n- **AI Agents for Treasury**:\n  - 📊 **Excel Report Generator** — Cash position, reconciliation, control totals, audit trail\n  - 📈 **Cash Flow Forecasting** — T+7, T+30, T+90 scenarios with covenant monitoring\n  - ✓ **Reconciliation Proposal Engine** — Multi-factor confidence scoring (60-100)\n  - 🚨 **Exception Detector** — Duplicates, stale items, threshold violations, FX anomalies\n- **Deterministic Agent Workflows**: Explainable AI proposals and audit traces without ungrounded ledger writes.\n\n---\n\n## 🛠️ Technology Stack\n\n- **Frontend**: React 19, TypeScript, Vite, React Router, TanStack Query, Lucide icons, Framer Motion, Three.js\n- **Backend**: Node.js 22, Express 5 REST API, Server-Sent Events (SSE)\n- **Design System**: Tailwind CSS, design tokens, accessibility (WCAG 2.2 AA)\n- **Persistence**:\n  - Local / Fast unit, security, and reconciliation tests\n- **Base Currency**: `AED` (strict zero-float decimal precision)\n\n---\n\n## 📚 Documentation & Technical Specifications\n\n| Document | Purpose all amounts use exact 2-decimal arithmetic.\n2. **Short-Lived JWTs**: Session tokens expire after 15 minutes.\n3. **Tenant & Entity Scoping**: Reads and writes validate the user's explicit legal entity assignments (`403 ENTITY_SCOPE_DENIED` on violation).\n4. **Dual-Control Invariant**: A maker can never approve their own proposed action.\n5. **Fail-Closed in Production**: Missing credentials or unverified origins reject all requests with `503`.\n6. **Immutable Audit Trail**: All maker-checker decisions cryptographically signed and stored.\n7. **No Autonomous Execution**: AI agents propose; humans always approve high-value actions.\n\n---\n\n## 🎯 Release Gate & Roadmap\n\n### ✅ Prototype UAT (Current Phase)\n- All 9 control totals reconciling\n- 56 automated tests passing\n- User workflows verified\n- Maker-checker dual-control enforced\n- SSE live stream operational\n- AI agents (reporting, forecasting, reconciliation) functional\n\n### 🔄 Phase 1: Production Pilot\nRequirements (from `docs/phase-1-production-blueprint.md`):\n- [ ] Identity & tenancy controls hardened\n- [ ] Durable audit logging with immutable storage\n- [ ] PostgreSQL migration & RLS policies tested\n- [ ] Idempotency & evidence storage production-ready\n- [ ] Deployment & scaling controls verified\n- [ ] Security audit completed\n- [ ] Data retention & compliance policies finalized\n\n### 📈 Phase 2+: Extended Capabilities\n- Multi-entity consolidation (IFRS 16)\n- Predictive anomaly detection (ML-based fraud scoring)\n- Autonomous payment execution (with dual-control override)\n- Advanced facility management & covenant optimization\n\n---\n\n## 🔗 Related Repositories\n\n1. **Production Code** (this repo): https://github.com/christophernemala/treasury-orchestration\n2. **Design System**: https://github.com/christophernemala/treasury-design-system\n3. **UAT Evidence**: https://github.com/christophernemala/treasury-atom-evidence\n\n---\n\n## 📞 Support & Questions\n\n- **Architecture & Design**: See [`REFERENCE.md`](REFERENCE.md) and [`docs/architecture.md`](docs/architecture.md)\n- **AI Agents & Workflows**: See [`AGENTS.md`](AGENTS.md) and [`docs/agent-capabilities.md`](docs/agent-capabilities.md)\n- **Design & UI**: See [`design.md`](design.md) and [treasury-design-system](https://github.com/christophernemala/treasury-design-system)\n- **UAT & Evidence**: See [treasury-atom-evidence](https://github.com/christophernemala/treasury-atom-evidence)\n- **Production Deployment**: See [`docs/phase-1-production-blueprint.md`](docs/phase-1-production-blueprint.md)\n"
